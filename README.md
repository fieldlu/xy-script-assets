# 小雅辅助工具

面向小雅平台的浏览器用户脚本。

---

## 功能

- 视频与文档自动播放
- 课件批量下载
- 作业导出为 Word 文档
- 作业 AI 作答：提取题目模板、粘贴 AI 回答、一键提交作答记录
- 讨论区互动
- 计划调度与全局雷达
- 脚本更新检查：一键比对最新版本、查看更新内容
- 一键反馈 Bug

---

## 安装

1. 安装 Tampermonkey 浏览器扩展
2. [点击安装脚本](https://scriptcat.org/zh-CN/script-show-page/5881)
3. 打开小雅平台即可使用

> 脚本已启用自动更新（`@downloadURL`），并内置「检查更新」面板，有新版会自动提示。

---

## 技术栈

纯原生 JavaScript，零外部依赖，基于 Tampermonkey API。
