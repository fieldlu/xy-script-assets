# 小雅辅助工具

面向小雅平台的浏览器用户脚本。

---

## 功能

- 视频与文档自动播放
- 课件批量下载
- 作业导出为 Word 文档
- 作业 AI 作答：提取题目模板、粘贴 AI 回答、一键提交作答记录
- 讨论区互动
- 计划调度与全局雷达
- 进行中课程总览：待办、任务完成率、累计学习时长与课程学情抽屉
- 脚本更新检查：一键比对最新版本、查看更新内容
- 一键反馈 Bug

---

## 安装

1. 安装 Tampermonkey 浏览器扩展
2. [点击安装最新版脚本](https://gitee.com/fieldlu/xy-script-assets/raw/main/%E5%B0%8F%E9%9B%85%E8%BE%85%E5%8A%A9%E5%B7%A5%E5%85%B7%20.user.js)
3. 打开小雅平台即可使用

> 脚本已启用 Gitee 自动更新（`@updateURL` / `@downloadURL`），并内置「检查更新」面板，有新版会自动提示。

---

## 技术栈

纯原生 JavaScript，零外部依赖，基于 Tampermonkey API。
