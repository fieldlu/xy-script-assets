# 🌸 小雅辅助工具 — 主人sama的学习小助手 ✨

[![version](https://img.shields.io/badge/version-3.4.1-pink)](https://gitee.com/fieldlu/xy-script-assets)
[![license](https://img.shields.io/badge/license-MIT-blue)](LICENSE)

> 「主人～今天的学习任务就交给小雅吧！(｡･ω･｡)ﾉ♡」

基于 `ai-augmented.com` 平台的全自动学习助手油猴脚本。本脚本以二次元萌妹风格打造，让枯燥的刷课变得有趣起来～💖

## 🎀 功能一览

### 📺 刷课引擎 — 全自动托管
- 🎬 视频/文档智能连播挂机，自动跳课，主人安心摸鱼就好～
- 🛡️ 防休眠 + **💓 后台保活看门狗**（v3.4.0 新增｜每 10s 巡检，心跳缺口超 75s 自动补发，定时器丢失自动重建，就算浏览器把定时器丢掉了小雅也会捡回来！）
- 🕵️ 深度伪装反检测（视界欺骗、暴力音轨剥离、鼠标模拟）—— 不会被老师发现的啦 (๑•̀ㅂ•́)و✧
- 📅 计划调度中心跨课编排
- ⚡ 全局任务雷达一键秒交

### ⏱️ 时长注入（v3.4.0 新增）
- 🎛️ UI 面板输入分钟数 → 自动拆分为合理心跳包序列发送
- 💻 控制台快捷命令：`xyInjectDuration(120)` / `xyStopInject()` / `xyKeepaliveStatus()`
- 📊 实时进度条，支持随时中断
- 🔄 每包 1.5s 间隔，失败自动重试（指数退避，最多 3 次）
