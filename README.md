# 小雅辅助工具

面向小雅平台的浏览器用户脚本。

---

## 功能

- 视频与文档自动播放
- 课件批量下载
- 作业导出为 Word 文档
- 讨论区互动

---

## 安装

1. 安装 Tampermonkey 浏览器扩展
2. 安装本脚本
3. 打开小雅平台即可使用

---

## 技术栈

纯原生 JavaScript，零外部依赖，基于 Tampermonkey API。

---

## 版本

当前版本 `3.5.5`
