## 功能

### 刷课引擎

- 视频、文档自动连播，自动跳转下一课
- 同课程按顺序跳、跨课程清完一门再下一门
- 跳转失败指数退避：5s → 10s → 20s → 40s → 80s → 10min
- 雷达 API 3 秒缓存 + 并发请求合并，减少重复请求

### 后台保活

- 7 个关键定时器全部防浏览器后台节流
- 看门狗每 10 秒巡检，心跳缺口超过 75 秒自动补发
- 切换回前台自动补偿错过的计时和心跳

### 任务雷达

- 一键扫描全网未完成任务，按截止时间倒序排列
- 视频和文档自动分拣，智能跳过已完成项
- 秒级批量提交，优先处理临近截止的任务

### 计划调度

- 跨课程自定义编排，每课独立设定策略
- 三种模式：达标连播、刷固定时长、无限循环
- 支持定时启停，到达设定时间自动开始/停止

### 课件下载

- 文件列表搜索过滤，全选智能适配搜索结果
- 批量下载实时进度条，支持暂停和终止
- Token 鉴权，加密链接自动 DES 解密

### 讨论区

- 批量点赞、自定义回复模板
- DOM 扫描 + 搜索过滤，一键清空讨论任务

### 深度伪装

- 鼠标贝塞尔曲线轨迹模拟
- 键盘随机敲击（Tab、方向键、空格）
- 滚动抖动和硬件静音注入

### 学时注入

- 手动输入分钟数，脚本拆分为心跳包高速发送
- 实时进度条，支持随时中断
- 300 分钟单次上限，注入期间自动阻止正常心跳防重复

> 学时注入为高危功能，面板默认折叠，需二次确认才能启动。

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展（支持 Chrome / Edge / Firefox）
2. 点击安装脚本：`https://gitee.com/fieldlu/xy-script-assets/raw/main/小雅辅助工具%20.user.js`

安装后油猴自动检测更新，每次发版都会收到升级提示。
